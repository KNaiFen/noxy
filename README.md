# Noxy / voxy-distant

Voxy Distant 是 Minecraft 1.20.1 / Forge 的远景扩展。单人游戏可在视距外生成真实区块；多人游戏由服务器生成并缓存 L0～L4 远景，客户端按距离接收并交给 Voxy 显示。运行需要 Java 21，扩展支持 Forge 47.4.0～47.x。

## 安装

0.2.16 安装包位于本地 [`dist/`](dist/)：`voxy-distant-0.2.16-forge-1.20.1.jar`。客户端与专用服务器安装**同一版本**，各自 `mods/` 中只保留一个 Voxy Distant JAR。

| 位置 | 安装内容 |
| --- | --- |
| 客户端 | Voxy Distant、Voxy 0.2.15-beta、Embeddium 0.3.31 |
| 专用服务器 | 仅 Voxy Distant；不安装 Voxy 或 Embeddium |

本地 `dist/` 提供上述三个 JAR 和 `SHA256SUMS.txt`；GitHub Release 提供公开安装包。`build/devlibs/` 中的开发命名空间 JAR 不能用于游戏安装。已有 `.voxy` 和服务端 LOD 缓存无需清理；升级前正常关闭游戏与服务器，再替换两端扩展。服务器未安装本扩展时客户端仍可连接，但不会进行远景同步。完整兼容条件与升级步骤见本地开发文档中的安装说明。

## 开始使用

安装后即可使用默认配置。客户端在原版视距外显示远景；进入更近的距离档位时请求更细数据，原版完整区块到达后由客户端转换接管。客户端接收范围由服务端上限、Voxy 渲染距离和本机配置共同决定。打开原版“选项”，点击与 DH 同位置的 **VD** 小按钮，即可在 Voxy Distant 菜单中调整本地生成、服务端接收、诊断日志及 OP 服务端设置。

服务器默认允许视距外生成，远景半径为 256 区块，分档为 `32:0,64:1,96:2`：32 区块内请求 L0、32～64 区块请求 L1、更远处请求 L2，直到实际接收边界。已有显式配置值不会因升级而覆盖。

拥有 OP 等级 2 的管理员可以使用：

| 命令 | 用途 |
| --- | --- |
| `/voxydistant stats` | 查看生成、缓存、导入和发送状态 |
| `/voxydistant reload` | 修改服务端配置文件后重载 |
| `/voxydistant import` | 从存档已有的完整区块刷新远景缓存，不生成新区块；运行期间暂停在线远景传输，结束后自动恢复 |
| `/voxydistant pregen <radius> <x> <z>` | 以当前维度的方块坐标 `x/z` 为中心，在指定区块半径内预生成缺失区块及远景 |

配置文件为客户端和服务器各自的 `config/voxy_distant.toml`。编辑服务器文件后执行 `/voxydistant reload`；游戏内服务端设置页也可由 OP 在线保存。`import` 可能大量占用 CPU，建议先查看服务器负载。

## 遇到问题

先确认 Minecraft、Forge、Java、Voxy Distant 和客户端配套模组版本，检查两端 `logs/latest.log`。如果远景加载异常，保留现有缓存以便定位；在菜单中开启两端诊断日志，记录坐标、时间、客户端及服务端日志。缓存加载与画面验证属于不同检查，不能仅凭请求队列清零认定画面已恢复。

如果保留旧缓存进服后短时间看到粗级地形，先在固定位置观察细节是否补齐，并记录出现与消失的时间。若始终不消失，请保留坐标、画面和双端日志用于排查。
